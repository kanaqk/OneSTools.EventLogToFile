# Проверки файлового экспорта

Требуется SDK .NET 10. Запуск из корня репозитория:

```bash
dotnet run --project tests/Exporter.SmokeTests
```

Проверяются JSON Lines и UTF-8, сохранение кириллицы и многострочных комментариев,
сохранение позиции и восстановление повреждённого хвоста длинной строки, удаление оборванного хвоста, добавление событий
после перезапуска, отмена записи, отказ при повреждённой полной строке, конвертация тестового
LGF/LGP с расшифровкой события и UTC, сброс неполной порции при завершении архива и остановке,
разделение порции между несколькими исходными файлами, один JSON на LGP,
продолжение последнего LGP после перезапуска, блокировка выходной папки,
сохранение предыдущей позиции при ошибке записи checkpoint,
ограничение одного потока записи, ошибка хранилища без зависания конвейера и пустой архив.
Тесты используют временный каталог и удаляют только созданные ими файлы.

Проверка конфигурации Filebeat через Docker:

```bash
docker run --rm --network none \
  -v "$PWD/examples/filebeat.yml:/usr/share/filebeat/filebeat.yml:ro" \
  docker.elastic.co/beats/filebeat:9.5.5 test config --strict.perms=false
```

При разработке также проверены запуск готового экспортера на .NET 10 с
`DOTNET_ROLL_FORWARD=Major`, чтение его файлов Filebeat 9.5.5 с выводом в консоль
(декодирование полей, кириллица и `@timestamp`) и остановка менеджера через SIGINT
с дописыванием последней порции. Подключение к реальному Elasticsearch не проверялось.
